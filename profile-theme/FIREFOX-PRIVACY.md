# Winter Profile: данные

Расширение не собирает и не передаёт данные автору или аналитическим сервисам. Нет телеметрии, рекламы, внешних исполняемых скриптов и запросов к API. Cookies, токены и пароли не используются.

В локальном хранилище расширения находятся настройки оформления, выбранные картинки фона и ники, которым пользователь назначил отдельные темы. Изображения не загружаются на сервер. История просмотра не ведётся. Текущий ник определяется только для выбора настроек открытого профиля, без чтения адресов других вкладок.

Сброс общих настроек заменяет их значениями по умолчанию; индивидуальные темы сохраняются. Возврат выбранного профиля к общему оформлению удаляет его отдельные настройки. Экспорт создаёт локальный JSON-файл с параметрами и активным фоном, без списка профилей, данных аккаунта и общего переключателя. Передача такого файла другому человеку выполняется самим пользователем.

Доступ к github.com используется для распознавания личного профиля и изменения его отображения в браузере. Имена, описания, ссылки, README и репозитории других пользователей не отправляются на сервер расширения. Сами страницы GitHub продолжают работать по правилам GitHub и загружать собственные ресурсы.

Вопросы по расширению: [GitHub Issues](https://github.com/psichopodobny/psichopodobny/issues).
