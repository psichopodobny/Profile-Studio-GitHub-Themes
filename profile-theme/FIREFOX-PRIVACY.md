# Winter Profile: данные

Расширение не собирает и не передаёт данные автору или аналитическим сервисам. Нет телеметрии, рекламы, внешних исполняемых скриптов и запросов к API. Cookies, токены и пароли не используются.

В локальном хранилище расширения находятся только настройки оформления и выбранная пользователем картинка фона. Изображение не загружается на сервер. Сброс оформления заменяет сохранённые настройки значениями по умолчанию и удаляет содержимое выбранного фона из хранилища расширения.

Доступ к github.com используется для распознавания личного профиля и изменения его отображения в браузере. Имена, описания, ссылки, README и репозитории других пользователей не отправляются на сервер расширения. Сами страницы GitHub продолжают работать по правилам GitHub и загружать собственные ресурсы.

Вопросы по расширению: [GitHub Issues](https://github.com/psichopodobny/psichopodobny/issues).
