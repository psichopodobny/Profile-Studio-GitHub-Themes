WINTER PROFILE 1.2.0

1. Распакуй ZIP в постоянную папку.
2. Chrome: открой chrome://extensions. Edge: edge://extensions.
3. Включи «Режим разработчика».
4. Нажми «Загрузить распакованное» и выбери папку с manifest.json.
5. Открой любой личный GitHub-профиль или обнови открытую страницу.
6. Через значок расширения выбери фон, цвет и шрифт.
7. Выбери общее оформление или отдельный ник. Тему можно сохранить в JSON и передать другому пользователю.

Настройки действуют локально у установившего расширение человека.
У других владельцев профилей сохраняются их имена, аватары и проекты.
Обычный GitHub возвращается кнопкой вверху страницы.
Включить оформление снова: значок расширения -> Кастомный профиль.

Полная инструкция и исходники:
https://github.com/psichopodobny/psichopodobny/tree/main/profile-theme

Не удаляй эту папку, пока пользуешься расширением.
