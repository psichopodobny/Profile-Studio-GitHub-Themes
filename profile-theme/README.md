# Winter Profile

Зимнее оформление **psichopodobny** и общей страницы **psichopodobny and uikole** для Chrome и Edge.

[**Скачать расширение v1.0.0**](https://github.com/psichopodobny/psichopodobny/raw/refs/heads/main/profile-theme/dist/psichopodobny-winter-v1.0.0.zip)

![Предпросмотр личного оформления](./preview-personal.webp)

Тёмный зимний фон, снег и туман, движение за курсором, световая рамка аватара и появление заголовков при прокрутке. Исходный портрет Аримы сохранён в размере 1080×1080, без повторного сжатия. На общей странице половина uikole остаётся цветной.

Расширение меняет отображение страниц в браузере установившего его человека. Остальные посетители видят обычный GitHub. Оно не меняет аккаунт, репозитории или настройки GitHub на сервере.

## Установка

1. Скачай ZIP по ссылке выше и распакуй его в постоянную папку.
2. Открой `chrome://extensions` в Chrome или `edge://extensions` в Edge.
3. Включи **Режим разработчика / Developer mode**.
4. Нажми **Загрузить распакованное / Load unpacked** и выбери распакованную папку, в которой лежит `manifest.json`.
5. Открой [профиль](https://github.com/psichopodobny) или [общую страницу](https://github.com/psichopodobny/psichopodobny-and-uikole). Если страница была открыта до установки, обнови её.

Это установка из исходников, без публикации в магазине. Порядок загрузки распакованного расширения описан в [документации Chrome](https://developer.chrome.com/docs/extensions/get-started/tutorial/hello-world#load-unpacked).

Не удаляй распакованную папку, пока используешь расширение. ZIP можно удалить после распаковки.

## Управление

- **Движение** - анимация появления, туман, рамка и лёгкое движение фона за курсором.
- **Снег** - отдельный переключатель частиц.
- **Обычный GitHub** - сразу возвращает исходную страницу. Включить оформление снова можно через значок расширения.

Системная настройка уменьшения движения учитывается автоматически. Анимации работают средствами браузера, без покадрового GIF. Частота зависит от экрана, браузера и нагрузки; фиксированные 60 FPS не навязываются.

Если переходишь сюда из другой страницы GitHub и оформление не включилось, обнови страницу или открой нужный профиль кнопкой в расширении. Навигация внутри GitHub иногда выполняется без полной загрузки страницы.

## Доступ и данные

Дополнительное разрешение - только локальное хранилище трёх переключателей. Скрипт загружается по узким адресным шаблонам внутри `github.com/psichopodobny`; проверка в коде включает оформление лишь на обзоре профиля и главной странице общего репозитория. Списки репозиториев, issues, настройки и исходники остаются обычными.

Нет аналитики, внешних скриптов, запросов к API, доступа к cookies или токенам. Иллюстрации, стили и код находятся внутри ZIP. При включении исходное содержимое страницы скрывается визуально; кнопка возврата показывает его снова.

## Исходники и проверка

Папка [extension](./extension) содержит полный код, который входит в ZIP. Проверки находятся в [tests](./tests).

```sh
npm install
npx playwright install chromium
npm test
```

Проверки запускают расширение в отдельном браузерном профиле на тестовых страницах, без входа в настоящий аккаунт. Проверяются адреса, загрузка ресурсов, переключатели, восстановление исходного вида, переходы без перезагрузки, мобильная компоновка и уменьшение движения. Дополнительно проверена загрузка на обеих публичных страницах GitHub; предпросмотры выше показывают их с включённым расширением.

Для обновления замени содержимое распакованной папки новой версией и нажми кнопку обновления на карточке расширения. Для удаления используй **Удалить / Remove** на странице расширений.
