# Profile Studio - GitHub Themes / 1.5.4

Редактор GitHub-профилей от psichopodobny и [uikole](https://github.com/uikoll).

## Новое

- Два независимых режима: обычный GitHub README и оформление страницы через расширение.
- Ctrl+K ищет настройки и сохранённые сборки. Enter открывает результат, Esc закрывает поиск.
- «До / Сейчас» сравнивает оформление. Кнопка + запоминает текущий вид до перезагрузки вкладки. Экспорт и сохранение используют текущий черновик.
- Своим сборкам можно давать названия и переименовывать их. Правки личного примера сохраняются после перезагрузки.
- Фон занимает видимую область, остаётся на месте при прокрутке контента и сохраняет смещение параллакса при настройке.
- 20 тем профиля и 20 независимых палитр редактора. Общий выбор цвета: HEX, RGB, насыщенность/яркость и вертикальная шкала тона.
- Отдельные аватар и рамка, свой PNG/APNG, цвет и скорость, шрифты, курсор, эффекты, проекты и мини-профиль.
- Темы владельцев из существующих публичных репозиториев, каталог и ремиксы. Онлайн-функции включаются пользователем.

## Запуск из исходников

Нужен Python 3.10+. Без npm и установки шрифтов в Windows:

```powershell
cd profile-theme/studio
python build.py
```

Открой `extension/studio.html`. Для постоянного адреса локального редактора можно выполнить `python -m http.server 8000 --directory extension` и перейти на http://127.0.0.1:8000/studio.html. Черновики сохраняются в IndexedDB текущего браузера; между адресами и браузерами их переносят через JSON.

Сборка создаёт локальные ZIP для Chromium, временной проверки в Firefox, HTML-редактора и исходников. Firefox ZIP не подписан и не является обновлением из Add-ons. Актуальная подписанная версия устанавливается [из Mozilla Add-ons](https://addons.mozilla.org/firefox/addon/profile-github-/).

Для Chrome/Edge/Brave: открой страницу расширений, включи режим разработчика и загрузи папку `extension`. Для временной проверки Firefox: `about:debugging#/runtime/this-firefox` → «Загрузить временное дополнение» → `firefox/manifest.json`. Firefox удаляет временное дополнение при перезапуске.

## Два режима

Обычный GitHub создаёт Markdown и SVG-баннер, поддерживает свой PNG/JPG/WebP/GIF, значки и проекты. После сохранения README на GitHub его видят все. Возможности оформления ограничены тем, что разрешает GitHub README.

С расширением меняется сама страница: фон, аватар, рамка, курсор и эффекты. Другой посетитель должен установить Profile Studio и включить «Темы владельцев». Профильный README для полной темы не требуется. Владельцу достаточно файла `profile-studio.json` в существующем публичном репозитории и заявки в каталоге под своим аккаунтом. Расширение проверяет авторство; другие могут импортировать или переделывать тему, если автор разрешил ремикс.

Редактор не загружает файлы автоматически: раздел публикации скачивает JSON и открывает страницу GitHub. Пароли и токены программе не передаются. Локальная тема конкретного профиля имеет приоритет над опубликованной.

## Размеры изображений

Фон компьютера: 2560×1440 (16:9), подходящий минимум 1920×1080. Телефон: 1440×2560 (9:16). Квадрат 1920×1920 тоже принимается: края обрезаются под экран; положение и масштаб можно изменить. PNG/JPG/WebP до 6 МБ, длинная сторона при импорте ограничивается 2560 px. Курсор: прозрачный PNG/WebP 48×48 px. Аватар: квадратное фото, до 6 МБ.

Широкий зимний лес реконструирован через image_gen по пользовательскому фото. Фактическое разрешение 1672×941, WebP quality 94. Запрос сохранён в `artwork/winter-forest-wide.prompt.txt`. Исходное портретное фото 716×1273 сохранено отдельно. Затемнение регулируется независимо.

## Рамки и проверка

Публичные исходники содержат собственные SVG-рамки и загрузку PNG/APNG. Исходные анимации Steam из локального сравнения не распространяются в этом репозитории. Поэтому публичная коллекция отличается от частного набора сравнения. Пользовательские файлы сохраняют свои права.

В [PUBLIC-VERIFICATION.json](test-results/PUBLIC-VERIFICATION.json) указаны фактически выполненные проверки именно публичного дерева. Подробности: [README-BUILD.md](README-BUILD.md). Публикации новой версии в Mozilla/Edge/Chrome не выполнялись.

Код и собственные SVG-материалы: [MIT](extension/LICENSE). Сторонние изображения и шрифты: [ARTWORK.md](extension/ARTWORK.md). Данные и сеть: [PRIVACY.md](extension/PRIVACY.md).
