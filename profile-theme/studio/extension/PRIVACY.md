# Profile Studio 1.5.4 - данные и сеть

Поиск настроек Ctrl+K выполняется локально и не передаёт поисковые запросы. Вариант «До» хранится только в памяти открытой вкладки, не попадает в экспорт и исчезает после её перезагрузки. Именованные сборки остаются в локальном IndexedDB.

Настройки, загруженные изображения, шрифты, курсор и тексты хранятся в браузере: черновик и локальные сборки в IndexedDB, активные темы расширения в storage.local. Аналитики, рекламы и серверной учётной записи Profile Studio нет. Cookies, пароли, токены и содержимое почты не запрашиваются.

Обычный локальный HTML не обращается к GitHub для загрузки тем. Онлайн-функции работают в расширении:

- При включённой функции «Темы владельцев» расширение запрашивает публичный `https://raw.githubusercontent.com/username/username/HEAD/profile-studio.json`. Если файл отсутствует, читается публичный каталог заявок с фильтром по автору и проверяется тема из указанного существующего репозитория того же владельца. Автор заявки должен совпадать с владельцем темы. GitHub получает ник посещённого профиля и обычные сетевые сведения запроса, включая IP. Cookies и заголовки авторизации не отправляются. По умолчанию функция выключена.
- По нажатию кнопок каталога выполняются запросы к публичному API GitHub и файлам выбранных авторов. Никакой список посещённых профилей на сервер Profile Studio не отправляется.
- Firefox запрашивает отдельное необязательное согласие browsingActivity перед онлайн-загрузками. Без него локальное редактирование работает, онлайн-загрузки блокируются.
- Загруженные темы ограничены по размеру, проверяются по схеме JSON и автору. Скрипты, HTML, CSS и произвольные внешние URL изображений не принимаются.
- Автоматическая публикация отсутствует. Экспорт создаёт локальный файл. По умолчанию в нём нет аватара, личных текстов, карточек проектов и ссылок мини-профиля. Их можно включить явно. Черновик issue открывается только после действия пользователя и отправляется им самостоятельно.

Позиция курсора используется только для местных эффектов и не сохраняется или передаётся. Базовая тема не содержит персональных текстов, аватаров, проектов и ссылок мини-профиля. Ссылки в карточках не запрашиваются до нажатия пользователем; переход выполняется обычным браузером. Отключение расширения восстанавливает исходные элементы GitHub. Для полного удаления локальных тем можно удалить расширение и данные локального редактора в браузере.

Два режима редактора сохраняют независимые черновики в IndexedDB. Режим обычного GitHub генерирует Markdown и SVG локально. Загруженный GIF копируется без изменения байтов. Экспорт README не является публикацией. Скопировать Markdown в буфер можно только по кнопке. Если пользователь явно выбрал HTTPS-ссылку на баннер, предпросмотр загружает изображение с указанного сайта; этот сайт получает обычные сведения сетевого запроса браузера. Ссылки на баннеры и значки могут входить в экспортируемый README. Общая тема расширения по-прежнему не принимает произвольные внешние URL фонов.
