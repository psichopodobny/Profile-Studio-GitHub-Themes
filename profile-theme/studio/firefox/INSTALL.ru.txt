Profile Studio 1.4.0 - GitHub Themes

Открой расширение и нажми «Открыть редактор». Укажи GitHub-ник, настрой оформление и нажми «Сохранить». Изменения применяются локально в браузере; аватар и README аккаунта GitHub на сервере не редактируются.

В Firefox устанавливай подписанную версию со страницы Mozilla Add-ons. Архив исходников и неподписанный пакет предназначены для разработки и проверки. Временная установка для разработчика: about:debugging#/runtime/this-firefox → «Загрузить временное дополнение» → manifest.json из распакованного Firefox-пакета.

Темы владельцев и онлайн-каталог включаются отдельно. Без согласия на browsingActivity локальный редактор работает, онлайн-загрузки не выполняются. Подробности: PRIVACY.md.
