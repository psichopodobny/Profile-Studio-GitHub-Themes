# Локальный предпросмотр автора

Скрипт `tools/create-local-preview.py` создаёт отдельную демонстрацию личного оформления psichopodobny из готовых ресурсов 1.3. Он не устанавливает расширение, не меняет настройки браузера и не редактирует GitHub.

Для запуска на Windows сначала помести распакованные файлы Firefox 1.3 в `%LOCALAPPDATA%\ProfileStudio\Firefox-1.3.0`, затем выполни `python tools/create-local-preview.py`. Открой созданный `%LOCALAPPDATA%\ProfileStudio\my-profile-preview.html` в браузере. В нём работают фон, снег, движение за курсором и переходы между разделами. Нужен Python 3.9+.

Чтобы видеть оформление на самой странице GitHub, в Firefox открой `about:debugging#/runtime/this-firefox`, выбери «Загрузить временное дополнение» и укажи `manifest.json` из подготовленной папки. После этого открой https://github.com/psichopodobny. Такая загрузка действует до перезапуска Firefox. Для обычной постоянной установки нужна подписанная Mozilla сборка.

Предпросмотр проверен в отдельном Chromium: изображения загружаются, портрет сохраняет исходные 1080 px, ошибок JavaScript нет. Установка в пользовательский Firefox автоматически не выполнялась.
