# Community draft

Начальные модули будущей общей программы Profile Studio. Они ещё не подключены, не протестированы как готовое расширение и не входят в релиз 1.3.

Цель: каждый пользователь создаёт и публикует собственное оформление; посетители с расширением видят тему владельца, могут сохранить её и переделать.

В `extension/` сохранены изменённые модули поверх исходников Studio 1.3: схема настроек, определение личных профилей, формат публичной публикации и черновой фоновый загрузчик. Остальные исходники основы находятся в `../profile-theme/studio/extension/`.

Дальше нужны подключение фонового скрипта и разрешений, показ темы владельца, публикация из редактора, галерея и переработка тем, проверки и новая документация приватности. При сетевой загрузке тем декларации данных Mozilla должны отражать передачу просматриваемого ника в URL запросов к GitHub. Утверждение «нет сетевых запросов» к этому будущему выпуску не применяется.
