# Artwork sources

The header combines the user's newly selected Arima frame with the user's winter apartment courtyard photograph. The original face and drawing are preserved. A precise clipping path removes the old room background, including the dark strip beside the left cheek. The footer is typographic SVG and contains no character image. The lily-field frame and the illustrated partner card are not displayed.

- Arima portrait: user attachment codex-clipboard-42308b19-0bf7-4391-a26d-74d7f4d70cec.png, preserved locally in source/arima-side-frame.png.
- Winter courtyard: user attachment codex-clipboard-c5797a27-fb29-4e9e-9a8d-3ee9028b3116.png.
- Motion-design reference inspected at the user's request: https://github.com/RealTenzo. Its banner was used only as a visual reference, not included in the delivered artwork.

Native SVG snow uses 60 animation steps per second; actual playback follows browser and display scheduling. The portrait and text remain fixed. The cycle is 8 seconds. Pixel comparisons of rendered endpoints at 0 and 8 seconds gave zero difference. GIF copies use 20 ms moving-frame delays (50 FPS); the encoder can combine static welcome frames. Image rights remain with their respective owners. No generated characters, JavaScript, counters or tracking services are used.
