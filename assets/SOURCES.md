# Artwork sources

The current personal header uses a high-resolution user-supplied Arima portrait, converted to monochrome and combined with image motion, moving typography, snowfall, light and mist. The face is kept clear of the mist. The footer is typographic SVG and contains no character image. The lily-field frame and the illustrated partner card are not displayed.

- Arima portrait: user attachment codex-clipboard-a5189fee-8e25-4ae3-a410-652ee9bd2c57.png, preserved locally in source/arima-frontal.png.
- Motion-design reference inspected at the user's request: https://github.com/RealTenzo. Its banner was used only as a visual reference, not included in the delivered artwork.

Image rights remain with their respective owners. No original-artist attribution was supplied with the attachments. GIF encoding, typography, layout, snow overlays, and SVG dividers were composed for these README pages. The GIFs loop without using tracking services or counters.
